# DAOS v0.1.4

Release date: 2026-04-24

## Intended scope

`v0.1.4` is a tooling hardening release on top of `v0.1.3b`.

It keeps the DAOS schema small, but fixes several places where the scripts could contradict the repo's portability and safe-update promises.

## Changes

### Added
- `docs/agent-integrations.md` now includes adapter guidance for Codex, Claude Code, and OpenClaw / Quinn.

### Fixed
- Portability review decisions now use POSIX-style durable-wiki paths so review-driven apply works consistently across Windows and Unix-like systems.
- Active-memory portability exports now validate requested sidecar files before creating the output bundle.
- Generated and updater-created manifests now use `framework_version: v0.1.4`.

### Hardened
- `daos_update.py` no longer says protected user-owned files were untouched when an additive migration was applied with a backup.
- Update migration records now include `user_owned_additive_migrations` for clearer auditability.

## Explicit non-goals

- no lane model change
- no automatic merge of conflicting durable wiki files
- no automatic activation of imported active-memory sidecars
- no new runtime integration layer beyond documentation of adapter shapes
