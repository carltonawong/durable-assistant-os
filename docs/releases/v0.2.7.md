# DAOS v0.2.7 - Receipts and agent-readable handoff polish

DAOS v0.2.7 packages the public hardening that landed after v0.2.6 into a small patch checkpoint.

## Added

- `use-daos doctor --json` now has a machine-readable receipt shape for automation and audits.
- `docs/semantic-handoff-receipt.md` defines a portable handoff receipt for exact resume proof.
- `llms.txt` and `docs/for-agents.md` give assistants a compact front door for the DAOS boundary, usage surface, and source-authority posture.

## Hardened

- Doctor output reports lane handoff identity mismatches separately from freshness so operators can distinguish stale handoffs from ambiguous work-object identity.
- `docs/repo-reconciliation-safety.md` documents a read-only first pass for stale, duplicate, or divergent checkouts before reset/cleanup.

## Changed

- Bumped package metadata and generated manifests to `0.2.7` / `v0.2.7`.

## Scope

Patch checkpoint only: no hosted runtime, autonomous control layer, private integration, or new memory layer.
