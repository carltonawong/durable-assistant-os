# DAOS v0.2.6 - Handoff lifecycle and semantic doctor checkpoint

DAOS v0.2.6 packages the public hardening after v0.2.5 into a named patch checkpoint.

## Added

- Adapter preflights for reply-anchor recovery and durable action-policy enforcement.
- `use-daos doctor` continuity ownership, handoff lifecycle, surface-inventory, and semantic handoff proof sections.
- Semantic-handoff warning for lifecycle-valid handoffs too generic for exact resume.

## Changed

- Documented deterministic compaction fallback expectations for bounded, redacted pre-drop handoffs.
- Aligned memory parity doctrine with newest-first `wiki/log.md` ordering.
- Bumped package metadata and generated manifests to `0.2.6` / `v0.2.6`.

## Scope

Patch checkpoint only: no hosted runtime, autonomous control layer, or private integration.
