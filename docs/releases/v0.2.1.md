# DAOS v0.2.1 Release Notes

Date: 2026-05-05

## Summary

`v0.2.1` is a post-release trust patch following `v0.2.0`. It fixes documentation/release-note mismatches and clarifies package verification. It does not change runtime behavior.

## Changes

- Removed public eval documentation that referenced continuity-debt runner scripts which were not tracked or release-ready.
- Updated the `v0.2.0` verification note to reflect the final local verification result: 149 Python unittest cases with 3 POSIX-only interactive skips.
- Clarified the `v0.2.1` npm package dry-run result and tightened the runtime payload boundary.
- Removed source-only eval/proof materials and eval helper scripts from the npm package payload.
- Removed the source-only adversarial eval runner from the npm package payload.
- Current dry-run package result: 62 entries, about 88.5 KB packed and about 329 KB unpacked.
- Clarified that `daos_continuity_*` experimental scripts are not included in the npm package.
- Bumped package metadata to `0.2.1`.

## Verification

Release verification for this patch:

```bash
npm run test:package
npm run test:pack-install
npm run test:release-front-door
npm pack --dry-run --json
```

Expected result:

- npm package payload tests pass
- packed-tarball install smoke passes
- release front-door tests pass
- npm dry-run package excludes tests, docs assets, eval/proof docs, eval examples, private eval bloat, the adversarial eval runner, and `daos_continuity_*` scripts

The broader Python unittest result for the original `v0.2.0` verification is recorded in `docs/releases/v0.2.0.md`. This patch's release gate is the npm package boundary plus packed-install/front-door smoke.

## Upgrade Notes

No user migration is required from `v0.2.0` to `v0.2.1`.

This patch changes release documentation and package metadata only. Existing DAOS homes, starter packs, and first-run commands are unchanged.

## Known Non-Goals

- No runtime behavior changes.
- No README positioning changes.
- No first-run flow changes.
- No repository restructure.
- No eval corpus reorganization.
- No promotion of experimental continuity-debt scripts.
- No promotion of source-only adversarial benchmark tooling into the npm package.
