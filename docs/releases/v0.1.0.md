# DAOS v0.1.0

Release date: 2026-04-20

## What this release is

`v0.1.0` is the first formal DAOS release baseline.

It captures the repo in its current public shape:
- starter pack + toolkit
- public memory/trust/lane doctrine
- harness/templates/examples for first-pass setup
- scripts for bootstrap, validation, update, and portability

## Release summary

### Added
- formal DAOS release baseline
- `CHANGELOG.md` for framework-facing release history
- `docs/releases/` as the repo home for release notes

### Clarified
- DAOS is strongest today as a methodology + tooling kit
- DAOS is not yet a full runtime integration layer by itself
- the default first-user path is still to copy `starter-pack/`

### Included in this baseline
- README front-door compression work
- public memory model docs
- setup/trust/lane docs
- starter-pack, templates, examples, and harness surfaces
- schema/core/update/portability tooling already present in the repo

## Notes for adopters

- Treat this as the first coherent public baseline, not as a locked 1.0 contract.
- Expect continued hardening around memory quality, maintenance posture, and repo usability before major feature/control-surface expansion.
- Prefer the default path: copy `starter-pack/`, fill the core files, validate, then calibrate after real use.
