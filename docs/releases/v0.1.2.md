# DAOS v0.1.2

Release date: 2026-04-21

## Intended scope

`v0.1.2` is a patch hardening release.

It does not change DAOS into a runtime-specific platform.
It makes the portable baseline more exact, more legible, and more installable.

## Changes

### Added
- Public named reset/wake-up artifact: `wiki/cache/reset-handoff.md`
- Locked mandatory baseline files written directly into `starter-pack/`
- Matching locked baseline spine in `examples/starter-pack-example/`
- Optional runtime-specific install layer: `docs/agent-integrations.md`
- First runtime-specific section: Hermes integration

### Changed
- DAOS read order now places reset handoff ahead of broader agent continuity when resuming after reset or long idle.
- Validator and safe-update tooling now recognize and restore the reset-handoff baseline artifact.
- Public memory docs now describe reset handoff as a first-class DAOS surface.
- Front-door docs now say more clearly that operators fill the starter files while the locked baseline files already ship with the pack.
- Runtime-specific guidance is now separated into an optional install layer instead of being mixed into the mandatory baseline.

### Hardened
- Tightened consistency across README, starter-pack docs, public memory docs, and baseline doctrine files.
- Tightened the distinction between portable DAOS baseline behavior and optional runtime-specific enforcement.
- Tightened starter-pack guidance so a new adopter can see more quickly what is already installed versus what they need to fill.

## Explicit non-goals

- no mandatory runtime-specific install requirement
- no heavy expansion of DAOS memory layers
- no broad new portability/control-surface expansion
- no claim that all runtimes now implement reset-handoff behavior equally

## Release intent

Use this release to make DAOS easier to adopt as a real starter baseline:
- the locked doctrine files are now part of the starter pack
- reset/wake-up continuity is clearer and more explicit
- runtime-specific installs are available as an optional layer, not a hidden requirement
