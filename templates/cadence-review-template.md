# Cadence Review Template

Use this template to support ongoing DAOS upkeep after the initial setup is in place.

Keep it light enough to run regularly.

## 1. Heartbeat / quick check-in

- What is foreground right now?
- What feels most at risk of slipping?
- Is anything newly urgent, blocked, or noisy?
- What is the smallest useful next move today?

## 2. Weekly review

- What moved this week?
- What stalled this week?
- Which lane carried the most pressure?
- Which reminders were useful versus noisy?
- What should be promoted, paused, or dropped?

## 3. Monthly reset

- Which lanes are still real and active?
- What should change in the current lane map?
- What has become clutter?
- What deserves a stronger support system?
- What should be simplified?

## 4. Event-trigger review

Use when a meaningful change happens:
- a project stalls repeatedly
- a lane becomes unusually high pressure
- reminders stop helping
- a trust or memory boundary fails
- a new recurring obligation appears

Questions:
- What changed?
- What layer should absorb the change?
- Does a default need to be updated?
- Does something need to be reclassified?
