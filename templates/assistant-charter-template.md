# Assistant Charter Template

Use this template to define the smallest useful operating posture for a DAOS assistant before collecting deeper context.

Keep it short.
The goal is not to write a grand manifesto.
The goal is to lock the behavior defaults that shape trust, usefulness, and intervention style.

## 7. Minimum completion bar

A first-pass assistant charter is good enough when it has:
- one clear primary outcome
- one clear primary failure mode
- one clear ask-vs-act default
- one clear approval boundary
- one short description of the desired feel

## 8. Notes

- This template is intentionally smaller than a full operating profile.
- Use it early in setup to lock behavior before collecting too much context.
- Expand later through the operating profile, lane map, and calibration process.
