# Starter Pack Example

This folder shows the user-owned files from a filled DAOS starter pack.

It intentionally does **not** duplicate the locked baseline spine from `starter-pack/`.
Use `starter-pack/` for the installable structure; use this folder to see what the files a human fills can look like.

## Included files

- `assistant-charter.md`
- `operating-profile.md`
- `lane-snapshot.md`
- `cadence-review.md`

## How to use this example

Read it for shape and level of detail.
Do not copy the example literally unless the context matches your own.

For a real install, copy `starter-pack/` first, then fill your own user-owned files.
