# Security Policy

## Reporting a vulnerability

If you discover a security issue, privacy issue, or sensitive weakness in DAOS or its surrounding operating guidance:

- do **not** post full exploit details in a public issue first
- report it privately through the safest available maintainer channel
- if GitHub Security Advisories are available for this repository, prefer that path

If you are unsure whether something is security-sensitive, treat it as sensitive first.

## Scope

Security concerns may include:
- unsafe default behavior in the harness
- dangerous guidance around approval boundaries or trust defaults
- accidental disclosure paths for private or instance-specific information
- repo instructions that could encourage insecure operational behavior

## Early-stage note

This project is still evolving.
That means some issues may be framework/doctrine issues rather than code-execution issues.
They still matter and should be reported responsibly.
